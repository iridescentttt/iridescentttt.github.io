# Taolin Zhang

Personal homepage and blog using a Quartz-style layout inspired by `lubits.ch`.

Search, dark mode, hash-based article routing, and footer profile links work as a Vite-managed static site.

Content is managed from Markdown and JSON:

- `content/profile.json`: name, email, GitHub, Google Scholar, and profile image.
- `content/pages/home.md`: homepage introduction, experience, publication placeholder, and honors.
- `content/publications.md`: publication entries, framework images, and paper/code links.
- `content/posts/*.md`: blog posts and notes.
- `src/content.generated.js`: generated by Node from `content/`; do not edit it by hand.

To add a blog post, create a new Markdown file in `content/posts/`:

```md
---
slug: posts/my-new-note
title: My New Note
date: Aug 14, 2026
tags:
  - notes
  - llm
order: 20
---

Write the post body here.
```

## Local development

```bash
npm install
npm start
```

Open `http://127.0.0.1:5173`, or the port printed by Vite if 5173 is already occupied.

While `npm start` is running, edits under `content/` are regenerated automatically.

## Homepage Content

Keep long structured sections out of Markdown when they need consistent styling. For publications, `content/pages/home.md` only calls:

```md
{{publications}}
```

Add or reorder papers in `content/publications.md`. Keep the `draft: true` frontmatter so the publications file is not treated as a standalone page. The publication file uses `.paper-list`, `.paper-entry`, `.paper-image`, and `.paper-copy` classes; the visual layout lives in `styles.css`.

## Production check

```bash
npm run check
npm run build
npm run preview
```

Open `http://127.0.0.1:4173`.

## GitHub Pages

Create a GitHub repository named `taolinzhang.github.io`, then push this folder:

```bash
git init
git add .
git commit -m "Initial personal homepage"
git branch -M main
git remote add origin git@github.com:taolinzhang/taolinzhang.github.io.git
git push -u origin main
```

Then open the repository settings on GitHub and set `Pages` source to `GitHub Actions`.

The workflow in `.github/workflows/deploy.yml` runs `npm ci` and `npm run build`, so Markdown content is generated automatically during deployment.
